# MAAMS

MAAMS or Mencari Akar-Akar Masalah Sosial is a web application that aims to help people to find the root of social problems. This project is part of the Software Engineering Project course at the University of Indonesia.

## Development

1. Clone the repository (SSH)
   ```sh
   git clone git@gitlab.cs.ui.ac.id:maams-ppl/maams-fe.git
   ```
2. Install Dependencies
   ```sh
   yarn install
   ```
3. Go to the project directory
   ```sh
   cd maams-fe
   ```
4. Run the project
   ```sh
   yarn dev
   ```

## Contributing

1. Pull the latest changes from the main branch
   ```sh
   git pull origin main
   ```
2. Create a new branch
   ```sh
   git checkout -b <ticket-number>-<feature-name>
   ```
3. Commit your changes
   ```sh
   yarn cz
   ```
4. Push to the branch
   ```sh
   git push origin <ticket-number>-<feature-name>
   ```
5. Create a pull request
6. Wait for the review
7. Merge the pull request
8. Delete the branch
   ```sh
   git branch -d <ticket-number>-<feature-name>
   ```
